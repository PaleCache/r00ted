A dark, dense interface built for people who live in chat all day: colored names, level badges, live voice presence, and read receipts.

cat MANIFEST.txt

Everything runs on your machine

Chat, roles, XP, and moderation run on the Node server itself. Voice runs through a Jitsi Meet instance the server connects to, wired into the same UI.

[VOICE]

Voice & screen share

Voice channels run on Jitsi Meet, embedded directly in the UI with live speaking indicators, mute/deafen, and screen share with picture-in-picture. Requires a Jitsi Meet instance to connect to.

[ROLES]

Custom roles & badges

Build roles with their own color, badge, and member list from an in chat manager. Admins assign them without touching a config file.

[XP]

Leveling & prestige

Members earn bonus XP just by being active (needs to be gambled before they actually receive it). Higher levels unlock gradient and animated name colors, badge slots, and prestige tiers.

[CRYPT]

Optional and simple encryption

Set a password and messages get encrypted client-side before they ever leave the browser. Anyone without the password sees a lock icon.

[LIVE]

Stream embeds

Pull in Kick and YouTube streams with automatic "now live" pings when a tracked streamer goes live.

[MOD]

Admin tooling

Slash commands for muting, clearing, redirecting, role changes, and annoying unpausable private youtube videos, built for fun with trolling friends in mind :).

[MUSIC]

Music Player

Built in music player that can play local files or stream songs from your server, Built in music bot that can share music videos via jitsi meet screen share or just songs if you like.

[LIVE]

Multi-View

From the live list click embed and watch multiple streams at once with the ability to switch chats from the drop down.

[TEXT]

Whispers

Talk to server members in private.

[FUN]

Casino

Play casino games crash, plinko, black jack, poker, etc.... singleplayer and multiplayer with friends!
